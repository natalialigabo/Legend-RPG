# ⚔️ Legend RPG

Um jogo de RPG em pixel art rodando diretamente no navegador, desenvolvido para praticar Lógica de Programação, Orientação a Objetos e Manipulação do DOM.

![Badge em Desenvolvimento](http://img.shields.io/static/v1?label=STATUS&message=EM%20DESENVOLVIMENTO&color=GREEN&style=for-the-badge)

## 📋 Sobre o Projeto

Este projeto nasceu de uma atividade acadêmica para estruturar classes de heróis e evoluiu para um mini-jogo interativo. O objetivo foi aplicar conceitos de Engenharia da Computação na prática, criando um sistema onde classes herdam atributos, mas possuem comportamentos únicos.

### ✨ Funcionalidades
- **Sistema de Classes:** 6 classes distintas (Mago, Guerreiro, Ninja, etc.) com atributos herdados.
- **Batalha por Turnos:** Lógica de ataque, defesa e uso de itens.
- **Exploração:** Movimentação do personagem pelo cenário e interação com NPCs.
- **Persistência de História:** Narrativa que se desenrola conforme o jogador avança.

## 📂 Estrutura dos Arquivos

Este repositório documenta a evolução do código em três etapas:

1.  **`class_herois.js`**: 
    - *A Atividade Original.* Focado puramente na lógica de Classes e Objetos (POO) conforme solicitado no exercício inicial.
    
2.  **`batalha_rpg.js`**: 
    - *A Primeira Evolução.* Aqui implementamos a lógica de batalha e interação básica via console e prompts.

3.  **`script.js`** (Atual):
    - *O Jogo Completo.* Versão final com interface gráfica, movimentação no mapa, sistema de colisão e manipulação avançada do DOM.

## 🚀 Como Rodar

1. Clone este repositório.
2. Abra o arquivo `index.html` no seu navegador.
3. Escolha seu herói e inicie a jornada!

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura semântica)
- **CSS3** (Animações, Grid, Flexbox e Pixel Art via CSS)
- **JavaScript ES6+** (Classes, Herança, Event Listeners, Game Loop)
